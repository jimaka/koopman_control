# 第 1 章 项目总览

## 1.1 工程目标

本工程面向一艘**双推进器无人船（USV）**，目标是学习其水平面动力学并实现模型预测控制（MPC）：

- **建模对象**：船体系三自由度速度状态 $[u, v, r]$——纵荡速度 $u$（m/s）、横荡速度 $v$（m/s）、艏摇角速度 $r$（rad/s）。位姿 $[x, y, \psi]$ **不进模型**，由外部欧拉积分恢复：
  $$\dot{x} = u\cos\psi - v\sin\psi,\qquad \dot{y} = u\sin\psi + v\cos\psi,\qquad \dot{\psi} = r$$
- **控制输入**：4 维推进器指令 $[c_p, \delta_p, c_s, \delta_s]$——左舷油门（%，量程约 $[-100, 100]$）、左舷舵角（度，限幅 $\pm 35°$）、右舷油门、右舷舵角。训练中使用的控制量是**执行器反馈**（`/system/chassis_feedback`），天然包含执行器延迟与饱和。
- **核心方法**：Deep-Koopman 算子——用神经网络把非线性动力学提升到高维潜空间，在潜空间学习一个**线性（仿射）算子** $z_{k+1} = \bar{A} z_k + \bar{B} u_k + b$；由于预测模型是线性的，MPC 退化为**凸二次规划（QP）**，可用 OSQP 在毫秒级求解，满足实船 $\geq 0.5$ s 控制周期。
- **部署形态**：Python（PyTorch）训练 → 导出潜空间权重 YAML / ONNX → C++（无 ROS 依赖的 `koopman_control` 库 + OSQP）→ 桥接实船 ROS 控制节点 `motion.cpp`。

# 第 2 章 数学原理与公式推导

## 2.1 Koopman 算子理论基础

### 2.1.1 从非线性系统到提升线性系统

考虑离散时间非线性控制仿射系统（船舶水平面动力学）：

$$x_{k+1} = f(x_k, u_k),\qquad x_k \in \mathcal{X} \subseteq \mathbb{R}^{n},\ u_k \in \mathcal{U} \subseteq \mathbb{R}^{m}$$

本工程中 $x = [u, v, r]$（$n=3$，动力学子状态），$u = [c_p, \delta_p, c_s, \delta_s]$（$m=4$）。

Koopman 算子理论的核心思想：存在一组**观测函数（字典）** $g: \mathcal{X} \to \mathbb{R}^{D}$（$D \gg n$），使得提升后的状态 $z = g(x)$ 的演化近似线性：

$$g(x_{k+1}) \approx \bar{A}\, g(x_k) + \bar{B}\, u_k + b$$

其中 $\bar{A} \in \mathbb{R}^{D\times D}$、$\bar{B} \in \mathbb{R}^{D\times m}$、$b \in \mathbb{R}^D$（仿射项，用于补偿归一化空间的非零稳态）。严格来说 Koopman 算子是作用在观测函数空间上的无限维线性算子 $\mathcal{K}: \phi \mapsto \phi \circ f$；有限维矩阵 $\bar{A}$ 是它在字典张成的子空间上的投影近似。Deep-Koopman 路线用神经网络自动学习字典的一部分（隐藏特征 $h(x)$），另一部分则由**物理先验闭式给定**（见 2.2）。

线性化带来的决定性工程收益：**多步预测可以预计算成矩阵乘法**（见 2.4 的 condensed 形式），MPC 从非凸非线性规划退化为凸 QP，可全局最优、毫秒级求解——这正是本工程最终架构（潜空间 QP-MPC + OSQP）的立足点。

### 2.1.2 残差参数化与谱半径

本工程所有版本的一步推进均采用**残差（增量）参数化**：

$$z_{k+1} = z_k + \big(A_w z_k + b_A\big) + B_w u_k = \underbrace{(I + A_w)}_{\bar{A}} z_k + b_A + B_w u_k$$

其中 $A_w$（`nn.Linear(D,D,bias=True)` 的 weight）与 $B_w$（`nn.Linear(4,D,bias=False)`）是可学参数。初始化 $A_w \sim \mathcal{N}(0, 0.01^2)$、$b_A=0$、$B_w$ 取 Xavier($\text{gain}=0.1$)，使初始 $\bar{A} \approx I$（近似恒等映射，谱半径 $\approx 1$ 的临界稳定起点），有利于多步 rollout 稳定起步。

**谱半径**定义为有效转移矩阵的最大特征值模：

$$\rho(\bar{A}) = \max_i |\lambda_i(I + A_w)|$$

实现见基类 `BaseKoopmanModel.spectral_radius()`（`koopman/model_v1_v2.py:35-43`，优先 `torch.linalg.eigvals`，失败时退化到最大奇异值上界）。训练中用软惩罚约束：

$$L_{stab} = \operatorname{relu}\big(\rho(\bar{A}) - \rho_{max}\big)^2$$

阈值 $\rho_{max}$：v1 取 1.01，v2/v3/v4 取 1.005（允许轻微 $>1$，理由见 2.1.3）；部署导出时 YAML 中存储 `A_weight = I + A_w`（把残差形式还原为真实一步矩阵），这一约定从 2026-05 的 v1 时代（`train_multistep_voyage.py@9bc9060` 的 `export_params_to_yaml`）延续至今未变。

### 2.1.3 多步 rollout 与误差发散的定量刻画

无 teacher-forcing 的 $K$ 步开环预测：$z_0 = g(x_0)$，然后

$$z_{k+1} = \bar{A} z_k + b + \bar{B} u_k,\qquad \hat{x}_{k+1} = C(z_{k+1})$$

其中 $C$ 为解码（v1/v2/v3 为切片 $z[{:}3]$，v4 为 decoder MLP）。评估在**反归一化物理量**上进行：$\hat{x}^{phys} = \hat{x} \cdot \sigma_{dyn} + \mu_{dyn}$。

为定量回答"误差是否随预测步数发散"，工程定义了一组发散指标（`koopman/evalkit.py:395-447`），全部基于逐步水平速度误差 $\mathrm{vel}_k = \sqrt{\Delta u_k^2 + \Delta v_k^2}$ 的 RMS 曲线：

| 指标 | 公式 | 判读 |
|---|---|---|
| `ratio_stepK_over_step1` | $\mathrm{vel}_K / \max(\mathrm{vel}_1, 10^{-6})$ | 理想 1~3；$>5$ 强烈发散 |
| `slope_loglog` | $\log k \sim \log \mathrm{vel}_k$ 最小二乘斜率 | $\approx 0$ 不增长；$\approx 1$ 线性累积；$>1$ 超线性发散 |
| `slope_linear` | $k \sim \mathrm{vel}_k$ 斜率 | m/s per step |
| `lyapunov_like` | $\mathrm{mean}_k \log(\mathrm{vel}_{k+1}/\mathrm{vel}_k)$ | $>0$ 即指数级发散 |
| `auc_error_curve` | $\mathrm{trapezoid}(\mathrm{vel}, k)/K$ | 误差曲线平均高度 |
| `monotonic_increasing` | $\forall \Delta \geq -10^{-4}$ | 单调性 |
| `instability_score` | $\mathrm{sigmoid}(\mathrm{slope\_loglog}) \cdot (1 + \mathrm{ratio}/10)$ | 选模惩罚因子 |

对残差线性传播器 $z \mapsto z + A z + B u$，单步误差的 $k$ 步复合为 $e_k \approx \sum_{j} \bar{A}^{j} e$，当 $\rho(\bar{A})>1$ 或 $\|\bar{A}\|>1$ 时含放大因子 $\|\bar{A}\|^k$——这是 v1 时代 $slope\_loglog \approx 1$（线性发散）、`divergent_sample_pct=99.9%` 的理论解释，也是谱惩罚与噪声注入（使误差相干累积变为随机游走式 $\sqrt{k}$ 增长）的设计依据。注意 $K=20$ 内 slope $<0.2$ 属有界次线性增长，并非指数发散（`docs/工程分析与优化.md:233`）；而第二轮优化实验证明长程误差增长主要来自**控制序列驱动的开环预测误差累积**而非数值发散——把 $\rho$ 压到 $<1$ 并不能压平长程曲线（见 3.6 节）。

## 2.2 字典函数形式与物理先验嵌入

### 2.2.1 设计原则：严格可观测 + 物理字典 + 黑盒残差

v1/v2/v3 采用"严格可观测（Strict Koopman）"结构：原始状态直接拼入潜空间，重构为零误差切片：

$$z = \big[\, x\;(3),\; \psi_{pif}(x)\;(D_{pif}),\; h_\theta(x)\;(D_h) \,\big] \in \mathbb{R}^{3 + D_{pif} + D_h}$$

- $x = [u_n, v_n, r_n]$：z-score 归一化后的动力学状态；
- $\psi_{pif}$：**闭式物理字典**（无可学参数），把 MMG/Abkowitz 型水动力方程中最典型的非线性项强行作为 Koopman 基函数；
- $h_\theta$：encoder MLP（`res_mlp([3,64,64,64,24])`），只学习"已知物理公式之外的未知干扰"。

这样神经网络不必"死记硬背"已知物理，部署侧 C++ 端也可机械复刻闭式字典（无需 decoder）。

### 2.2.2 v1/v2 的 5 阶字典（`koopman/model_v1_v2.py:84-103`）

$$\psi_{pif}^{(5)}(x) = \big[\, u|u|,\; v|v|,\; r|r|,\; v r,\; u r \,\big] \in \mathbb{R}^5$$

- $u|u|, v|v|, r|r|$：二次阻尼（Quadratic Damping）项；
- $vr, ur$：科里奥利/向心耦合项。

总潜空间维度 $D = 3 + 5 + 24 = 32$（`model_v1_v2.py:62-65`）。`reconstruct_state(z) = z[{:}3]`（`:115`），`latent_step` 为残差式（`:118`），`A` 带 bias 以补偿归一化空间非零稳态（`:70-72`）。

### 2.2.3 v3 的 16 阶字典（`koopman/model_v3.py:27-66`）

在 5 个二次项基础上追加 11 个三次项，固定顺序由 `FEATURE_DICT_ATOMS` 定义（顺序是硬约束：YAML 序列化与 C++ 部署必须逐位对齐）：

$$\psi_{pif}^{(16)} = \big[\, \underbrace{u|u|, v|v|, r|r|, vr, ur}_{\text{二次（5）}},\; \underbrace{uvr,\ u^2r,\ v^2r,\ ur^2,\ vr^2,\ u|v|v,\ v|u|u,\ r|u|u,\ r|v|v,\ u^2|u|,\ v^2|v|}_{\text{三次（11）}} \,\big]$$

其中 $u^2|u|$（`uuu`）、$v^2|v|$（`vvv`）为三阶阻尼项，$u|v|v$ 等为三阶耦合项。全部闭式、无可学权重；输出前 `clamp(±5)`（`clamp_pif=5.0`）防极端样本下三次项数值爆炸（`model_v3.py:138-139`）；`n_cubic ∈ [0,11]` 可截取三次项数量。总维度 $D = 3 + 16 + 24 = 43$。

设计动机：v2 遗留的 u 通道线性漂移（$u\_bias=-0.00255$ 随步单调累积）与高速强耦合段误差（worst/best 段差 3.47×），需要更强的大舵角、强耦合工况表达能力。v3 另有 `_self_check_dict(tol=1e-6)`（`model_v3.py:186-230`）用人工输入 $[0.5, -0.3, 0.2]$ 逐项断言 16 个 atom 实现正确，训练启动时必触发。

### 2.2.4 v4 的 dict 输入结构（`new_v4_dict_input/model_v4_dict_input.py:77-159`）

v4 做了结构性改变：**物理字典从"潜空间的一部分"升格为"模型的主输入"**，同时移除状态直通分量：

$$z = \big[\, \psi_{pif}^{(16)}(x)\;(16),\; h_\theta\big(\psi_{pif}^{(16)}(x)\big)\;(32) \,\big] \in \mathbb{R}^{48}$$

- 16 个 atom 与 v3 逐位一致（`FEATURE_DICT_ATOMS_16`，`model_v4_dict_input.py:23-52`），clamp $\pm 5$；
- encoder 输入是 16 维字典而非原始状态：$\mathrm{encode}(x) = \mathrm{cat}[\mathrm{atoms16}(x),\ \mathrm{encoder\_mlp}(\mathrm{atoms16}(x))]$（`:150-153`）；
- 因 latent 不再含 $[u,v,r]$ 直通，必须新增 **decoder MLP**（48→64→64→3，GELU）从 latent 回归动力学状态：$\mathrm{reconstruct\_state}(z) = \mathrm{decoder}(z)$（`:155-156`）。重构不再零误差，需 $L_{recon}$ 训练（$w_{recon}=0.5$）。

encoder 双架构（`model_v4_dict_input.py:98-109`）：`"conv"`（默认，`res_mlp([16,64,64,32])`，其 depthwise Conv1d 作用在长度=1 序列上**退化为逐通道仿射**，仅为旧 ckpt 兼容保留）与 `"mlp"`（`_ResidualMLPEncoder`，标准 Linear+GELU+残差块，消融实验证明更优，见 3.6 节）。

动力学与初始化与 v1~v3 相同：`A = \mathrm{Linear}(48,48,\text{bias=True})$，$A_w \sim \mathcal{N}(0,0.01^2)$，$B = \mathrm{Linear}(4,48,\text{bias=False})$ Xavier(0.1)。

## 2.3 A/B 矩阵的学习方式与训练损失

### 2.3.1 端到端学习（非 EDMD 最小二乘）

A、B 是普通 `nn.Linear` 权重，与 encoder（v4 还有 decoder）**联合端到端反向传播**，没有单独的最小二乘/EDMD 求解步骤。稳定性不靠硬约束，而靠：$L_{stab}$ 软惩罚 + 初始化在 $\rho \approx 1$ 附近 + $L_{l2} = \|A_w\|^2 + \|B_w\|^2$（权重 $10^{-4}$）收缩。

### 2.3.2 v2 系完整损失体系（`scripts/train_v2.py:396-521`）

rollout 在归一化空间进行：$z = \mathrm{encode}(x_0)$，循环 $z \leftarrow \mathrm{latent\_step}(z, u_k)$。记物理量误差 $e_k = \hat{x}^{phys}_k - x^{phys}_k$（$B \times K \times 3$），步权重 $w_k = \gamma^k / \mathrm{mean}(\gamma^k)$（$\gamma = \gamma_{step} = 0.97$），通道缩放 $s = 1/\sigma_{dyn}$：

$$L = w_{vel} L_{vel} + w_{acc} L_{acc} + w_{lin}\cdot r \cdot L_{lin} + w_{recon} L_{recon} + w_{stab}\cdot r \cdot L_{stab} + w_{l2} L_{l2} + w_{bias} L_{bias} + w_{slope} L_{slope}$$

其中 $r = \min(1, (epoch+1)/5)$ 为 ramp-up 系数。各项定义与默认权重：

| 损失 | 公式 | 默认权重 |
|---|---|---|
| $L_{vel}$ | $\mathrm{mean}\big(\mathrm{huber}_{\beta=0.1}(e \odot s) \cdot w_k\big)$，物理速度 Huber 主损失 | 1.0 |
| $L_{acc}$ | 相邻步差分加速度误差 Huber（同加权） | 0.2 |
| $L_{lin}$ | $\mathrm{MSE}\big(\mathrm{rollout}\ z_k,\ \mathrm{encode}(x^{GT}_k)\big)$，潜空间线性一致性（前 5 epoch ramp） | 1.0 |
| $L_{recon}$ | $\mathrm{MSE}(\mathrm{decode}(\mathrm{encode}(x_0)), x_0)$（v1/v2/v3 恒为 0，v4 必需 0.5） | 0.0 / 0.5(v4) |
| $L_{stab}$ | $\mathrm{relu}(\rho(\bar A) - 1.005)^2$ | 0.1 |
| $L_{l2}$ | $\|A_w\|^2 + \|B_w\|^2$ | $10^{-4}$ |
| $L_{bias}$ | $\mathrm{mean}\big(\bar{e}_k^2 \cdot 1.05^k \cdot w_{chan}\big)$，$\bar e_k = \mathrm{mean}_{batch}(e_k \odot s)$；$\gamma_{bias}=1.05>1$ 强调晚期步；v3 起支持 per-channel $w_{bias\_u/v/r}$ | 0（v3a 推荐 $w_{bias\_v}=100$） |
| $L_{slope}$ | $\mathrm{relu}(\hat{s} - 0.65)^2$，$\hat s$ 为 batch 内 vel_rmse-per-step 在 log-log 上的闭式最小二乘斜率 $\hat{s} = \frac{n S_{xy} - S_x S_y}{n S_{xx} - S_x^2}$ | 0 |

v1 的损失与此不同（`scripts/train_v1.py:168-180`）：主损失是反归一化**加速度 MSE**（$w_{acc}=100$）+ $L_{lin}$（$w=15$）+ $L_{stab}$（$\rho_{max}=1.01$，$w=0.1$），验证/选模均用加速度损失——这导致速度"形似但漂移"（系统性 bias 随步单调累积，$slope\_loglog \approx 1$），是 v2 重写的直接动因。

v4 的损失（`new_v4_dict_input/train_v4_dict_input.py:327-411`）在 v2 基础上：去掉 $L_{bias}/L_{slope}$，$L_{recon}$ 必需（0.5），新增**位姿损失** $L_{xy}/L_{yaw}$——预测速度经船体系欧拉积分与 GT 位姿对齐（xy 用 MSE，yaw 经 wrap 后用 Huber），默认 $w_{xy}=2.0, w_{yaw}=1.0$，前 10 epoch ramp。

### 2.3.3 噪声注入（数据增强）

仅 `model.training=True` 时：对 t0 归一化状态加 $\mathcal{N}(0, \sigma_s^2)$（`--noise_std`，建议实船 0.02~0.03），对每步控制加 $\mathcal{N}(0, \sigma_c^2)$（`--ctrl_noise_std`，建议 0.003~0.005）。设计意图：迫使 encoder/算子对输入扰动鲁棒，把推理时每步误差的相干（同向）累加变为随机游走式增长，是打破 $slope\_loglog = 1$ 的"主导杠杆"（606fbef 提交结论）。监督信号（GT 目标序列）保持干净，eval/导出时 $\sigma=0$。

### 2.3.4 选模指标（composite 族）

- v2 起：`composite = vel\_rmse\_mean \times \max(1, instability\_score)$（`scripts/train_v2.py:765-769`）；
- v3a（Plan-A）：$\mathrm{composite\_v3a} = \mathrm{composite} \times \big(1 + 2\max(0, \mathrm{slope\_loglog} - 0.65)\big) \times \big(1 + 5\max(0, \mathrm{degraded\_pct}/100 - 0.18)\big)$（`train_v2.py:662-678`），其中 degraded_pct 为当前模型在 val 上末步速度误差超过 v1 baseline 的样本占比（`V1BaselineValCache`，`train_v2.py:584-659`）；
- v4：固定 `test/vel_rmse_mean × max(1, instability_score)`。

## 2.4 多步预测的 condensed 形式

将 $N$ 步（$N$ = MPC horizon）rollout 压缩为仿射形式（`cpp/koopman_control/src/koopman_latent_model.cpp:77-128` 与 Python 参考 `tests/test_latent_qp_matrices.py:20-45`）：

$$Z = \Gamma z_0 + \Theta U + \xi$$

- $Z = [z_1; \dots; z_N] \in \mathbb{R}^{n_z N}$，$U = [\tilde{u}_0; \dots; \tilde{u}_{N-1}] \in \mathbb{R}^{n_u N}$，$\tilde u = (u_{phys} - \mu_{ctrl})/\sigma_{ctrl}$ 为归一化控制；
- $\Gamma = [\bar A; \bar A^2; \dots; \bar A^N] \in \mathbb{R}^{n_z N \times n_z}$；
- $\Theta$ 为下三角块 Toeplitz 矩阵：第 $k$ 行块、第 $j$ 列块（$k=1..N,\ j=0..k-1$）为 $\bar A^{k-j-1} \bar B$，维度 $n_z N \times n_u N$；
- $\xi_k = \sum_{i=0}^{k-1} \bar A^i b$，堆叠为 $\xi \in \mathbb{R}^{n_z N}$。

`freeResponse(z0) = Γz0 + ξ`，`predictStacked(z0,U) = free + ΘU`。v4 默认维度（$n_z=48, n_u=4, N=20$）：$\bar A$ 48×48，$\bar B$ 48×4，$\Theta$ 960×80；当前部署配置（$N=10$，dt=4s）：$\Theta$ 480×40。Python 侧（float64）与逐步 rollout 的误差 $\leq 10^{-4}$，C++ 侧（float32）验证容差 $10^{-3}$。

## 2.5 MMG 操纵性模型方程与参数辨识

### 2.5.1 改型双推进器 MMG 方程（`koopman/mmg_model.py:5-10, 164-177`）

经典 MMG 的输入是"螺旋桨 RPM + 舵角"；本船为双推进器"油门%（±100）+ 推力矢量角（±35° 实船 / ±89° 仿真）"，故推进器模块改型为**推力随油门线性、推力矢量随舵角旋转**。状态方程（每单位质量/惯量参数化）：

$$
\begin{aligned}
\dot{u} &= v r + X_u u + X_{uu}\, u|u| + k_{tx}\,(c_p\cos\delta_p + c_s\cos\delta_s) \\
\dot{v} &= -u r + Y_v v + Y_r r + Y_{vv}\, v|v| + Y_{rr}\, r|r| + Y_{vr}\, v r + k_{ty}\,(c_p\sin\delta_p + c_s\sin\delta_s) \\
\dot{r} &= N_v v + N_r r + N_{rr}\, r|r| + N_{vr}\, v r + k_{tn\_lat}\,(c_p\sin\delta_p + c_s\sin\delta_s) + k_{tn\_diff}\,(c_s\cos\delta_s - c_p\cos\delta_p)
\end{aligned}
$$

- $vr, -ur$：刚体科氏耦合（无参数）；$u|u|, v|v|, r|r|$：二次阻尼；$vr$ 交叉项；
- 推进组合量：$lon = c_p\cos\delta_p + c_s\cos\delta_s$（纵向合力）、$lat = c_p\sin\delta_p + c_s\sin\delta_s$（横向合力）、$dif = c_s\cos\delta_s - c_p\cos\delta_p$（右−左纵向推力差）；舵角模型内部 deg2rad；
- $k_{tn\_lat}$：横向推力经纵向力臂产生的回转力矩；$k_{tn\_diff}$：左右舷推力差经横向间距产生的力矩，是**原地差速回转主导项**（对应左转补充数据的 $\delta=0$ 纯差速工况）；
- 共 **15 个参数**（`MMG_PARAM_NAMES`，`mmg_model.py:31-39`）：surge 3（$X_u, X_{uu}, k_{tx}$）、sway 6（$Y_v, Y_r, Y_{vv}, Y_{rr}, Y_{vr}, k_{ty}$）、yaw 6（$N_v, N_r, N_{rr}, N_{vr}, k_{tn\_lat}, k_{tn\_diff}$）。质量 $m$、$I_{zz}$ 与水动力导数/推力增益不可分，只能辨识"每单位质量/惯量"组合量，对预测无影响。

离散积分 `MmgModel.step_phys(dyn, ctrl, dt)`（`mmg_model.py:179-186`）：把 dt 按 $sub\_dt=0.1$ s 细分为 $n = \mathrm{round}(dt/0.1)$ 步显式 Euler，控制量零阶保持（ZOH）。

### 2.5.2 最小二乘参数辨识（`least_squares_fit`，`mmg_model.py:55-145`）

方程对全部未知参数线性，一步可解：

1. **预处理**：每段 $(u,v,r)$ 做 5 点等权滑动平均抑制差分噪声，前向差分得加速度；特征与差分对齐到平滑区中部，过短段跳过；
2. **回归构造**：科氏项移到左边——$targ_u = \dot u - vr$、$targ_v = \dot v + ur$、$targ_r = \dot r$；三通道特征分别为 $[u, u|u|, lon]$、$[v, r, v|v|, r|r|, vr, lat]$、$[v, r, r|r|, vr, lat, dif]$；
3. **求解**：岭正则以增广最小二乘实现（$\Phi \leftarrow [\Phi; \sqrt{\lambda} I]$，$\lambda=10^{-6}$），`np.linalg.lstsq`（SVD，避免法方程条件数平方）；
4. **产物**：$\theta \in \mathbb{R}^{15}$ + 拟合报告 + z-score 统计存入 `checkpoints/mmg_baseline.npz`。

实测辨识结果（训练集 `koopman_train_merged.npz`，99 段/5.5h，回归样本 n=197,406）：surge 通道 $R^2 = 0.5817$（线性+二次阻尼结构只解释约六成纵向加速度方差——残差 MLP 的吸收对象）、sway $R^2 = 0.9802$、yaw $R^2 = 0.99980$。注意个别参数物理符号反常（如 $Y_{rr}=+47.8$ 为正反馈）：$r$ 与 $r|r|$ 类特征存在**结构性相关**（系统辨识固有的多重共线性病态），逐参数物理解读不可靠，只有"预测等价"有意义（`tests/test_mmg_model.py:80-83` 的注释明确说明这一点）。

## 2.6 残差 MLP 混合模型（`koopman/mmg_residual.py`）

灰箱结构：**冻结的 MMG 物理基线 + 学习未建模动态残差的 MLP**：

$$\ddot{x} = f_{MMG}(x, u; \theta_{冻结}) + g_{MLP}\big(\mathrm{normalize}(x, u)\big)$$

- `ResidualMLP`（`mmg_residual.py:30-46`）：`Linear(7→64) → SiLU → 2×ResidualBlock(64) → Linear(64→3)`，**输出层权重与偏置零初始化**——训练起点严格等于纯 MMG 基线，训练单调改善；可训练参数 17,347；
- 输入为 z-score 归一化的 $[u,v,r,c_p,\delta_p,c_s,\delta_s]$ 7 维；输出为**物理加速度残差**，直接加到 MMG 加速度上；
- 训练目标：多步无 teacher-forcing rollout，$err = (\hat x - x)/\sigma_{dyn}$，Huber($\beta=0.1$) × 步折扣权重 $0.95^k$（早步权重高）；课程式 K：4 步起每 3 epoch +4 至 $K_{max}=40$（dt=0.5s × 40 = 20s）。

三方对比实测（`eval_out/mmg_compare/`，测试集 dt=0.1s、K=200=20s、n=4000）：MMG+残差 20s 速度 RMSE **0.00958 m/s**，比纯 MMG（0.109）改善 11.4 倍、比 v4 Koopman（0.166）改善 17 倍；traj_xy@200：0.128 m vs MMG 1.275 m vs v4 1.884 m。详见 3.8 节。

## 2.7 卡尔曼滤波：完整推导与工程角色

### 2.7.1 工程角色定位（先说结论）

`koopman/estimation/`（含 `kalman.py`，181 行）是一个**独立的线性卡尔曼滤波参考实现 + 教学/验证工具，当前并未接入 Koopman MPC 控制链路**。实船闭环中的状态 $(u, v, r)$ 直接来自上游 ROS 定位融合话题 `/localization/fusion_pose`，由 `cpp/motion.cpp` 原样消费——`velocity.x/y` 取融合定位原始输出，`yaw_rate_` 为相邻两帧 yaw 角的有限差分（`cpp/motion.cpp:152-158`，仅 $dt > 0.1$ s 时更新）。`docs/卡尔曼滤波推导.md:5` 明确声明该模块"不替代上游融合定位，也不接入 motion.cpp / MPC"；`motion.cpp:180-186` 的一段 RLS 在线辨识代码已被注释停用。Kalman 在工程规划中的未来角色是 P3 阶段的**残差观测器**——在线估计慢变偏置 $d$（风流扰动）作为 Koopman 模型的补偿项（`docs/仿真到实船优化指南.md:384-414`，产品代码尚未接入，对应文献中的 offset-free MPC，见第 6 章）。

### 2.7.2 状态空间模型与最优准则

线性高斯系统（`kalman.py:36-37`）：

$$x_k = F x_{k-1} + B u_{k-1} + w_{k-1},\quad w \sim \mathcal{N}(0, Q);\qquad z_k = H x_k + v_k,\quad v \sim \mathcal{N}(0, R)$$

状态 $x \in \mathbb{R}^n$，控制 $u \in \mathbb{R}^m$，观测 $z \in \mathbb{R}^p$；$w, v$ 零均值白噪声、互不相关；$Q \succeq 0$、$R \succ 0$（正定保证创新协方差 $S$ 可逆）。MMSE 准则下最优估计为条件均值 $\hat{x}_{k|k} = \mathbb{E}[x_k \mid z_{1:k}, u_{0:k-1}]$；线性高斯假设下条件分布仍为高斯，递推实现即卡尔曼滤波，分预测、更新两步。

### 2.7.3 预测步（时间更新）

$$\hat{x}_{k|k-1} = F \hat{x}_{k-1|k-1} + B u_{k-1},\qquad P_{k|k-1} = F P_{k-1|k-1} F^\top + Q$$

实现（`kalman.py:85-100`）：无 `B` 时禁止传 `u`；之后 $P \leftarrow \tfrac12(P + P^\top)$ 数值对称化。

### 2.7.4 更新步（测量更新）

创新（innovation）与其协方差：

$$y_k = z_k - H \hat{x}_{k|k-1},\qquad S_k = H P_{k|k-1} H^\top + R$$

由联合高斯条件均值公式 $\mathbb{E}[x|z] = \mu_x + \Sigma_{xz}\Sigma_{zz}^{-1}(z - \mu_z)$（其中 $\Sigma_{xz} = P_{k|k-1} H^\top$、$\Sigma_{zz} = S_k$），得：

$$\hat{x}_{k|k} = \hat{x}_{k|k-1} + K_k y_k,\qquad K_k = P_{k|k-1} H^\top S_k^{-1}$$

（正交原理 $\mathbb{E}[(x - \hat x) y^\top] = 0$ 可解出同一个 $K$，推导文档 §4.3 给出该等价推导。）协方差更新有两种代数等价形式：

- 朴素式：$P_{k|k} = (I - K_k H) P_{k|k-1}$
- **Joseph 式（默认）**：$P_{k|k} = (I - K_k H) P_{k|k-1} (I - K_k H)^\top + K_k R K_k^\top$

$K$ 恰为最优时两者代数等价（测试验证差 $<10^{-10}$）；$K$ 有数值误差时 Joseph 式仍保持对称半正定，故为工程推荐（`kalman.py:117-119`，`joseph=True` 默认开启）。

### 2.7.5 数值实现要点（与推导文档 §4.4/§4.5 一一对应）

- 增益计算**避免显式求逆**：$K = \mathrm{solve}(S^\top, (P H^\top)^\top)^\top$（`kalman.py:111-113`），即解线性方程组而非 `inv(S)`；
- 每步 $P$、$S$ 对称化；
- `filter(zs, us)` 批量滤波返回 `{x, P, innov, S}`——创新序列与协方差显式保留，用于 NIS 一致性检查 $y^\top S^{-1} y$。

### 2.7.6 噪声矩阵设计范例（`scripts/demo_kalman.py`）

演示为 2D 常速模型：状态 $x = [p_x, v_x, p_y, v_y]^\top$（4 维），观测位置 $[p_x, p_y]$（2 维）：

$$F = \begin{bmatrix} 1 & dt & 0 & 0 \\ 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & dt \\ 0 & 0 & 0 & 1 \end{bmatrix},\qquad H = \begin{bmatrix} 1 & 0 & 0 & 0 \\ 0 & 0 & 1 & 0 \end{bmatrix}$$

- **Q：连续白噪声加速度模型（CWNA）离散化**——每个运动轴的 2×2 块为 $q \begin{bmatrix} dt^3/3 & dt^2/2 \\ dt^2/2 & dt \end{bmatrix}$，两轴块对角拼成 4×4，$q = q_{std}^2$ 为加速度谱密度；
- **R = $r_{std}^2 I_2$**：各向同性位置观测噪声。

调参直觉（推导文档 §6）：先按传感器手册定 R，再扫 Q；Q 大→增益大→更跟观测更"抖"，R 大→更平滑更滞后；用创新白化程度与 NIS 做一致性检查。$(F, H)$ 可观时误差协方差有意义地收敛。演示实测（T=100, dt=0.1, $q_{std}=0.5, r_{std}=1.0$）：原始观测 RMSE 1.0041 → KF 滤波 RMSE 0.4106，改善 59.1%。

### 2.7.7 与训练侧噪声增强的边界

`docs/数据增强技术方案.md:224-247` 论证了"不先手工滤波再训练"：滤波会改变 $(u,v,r)$ 相位，若训练未见过滤波后统计会制造新域差；故选择训练期注入噪声（`--noise_std`）让模型在与部署相同的观测定义下学会抗噪，部署侧滤波/观测器仅作补充。Kalman 文档行 274 与之印证："训练噪声增强是训练域鲁棒性，不是在线滤波"。

## 2.8 潜空间 QP-MPC 完整推导

### 2.8.1 分层结构

当前 master 的 MPC **只保留一条求解路径：C++ OSQP 潜空间 condensed QP**（Python Adam/投影梯度 MPC 已在 0a92a65 中删除）。系统分四层（`cpp/koopman_control/模型输入输出接口说明.md:37-43`）：

| 层 | 类/文件 | 作用 |
|---|---|---|
| ⓪ 潜空间权重 | `KoopmanLatentModel` + `KoopmanEncoder`/`KoopmanDecoder` | 从 `koopman_v4_latent.yaml` 加载 $\bar A, \bar B, b$、encoder、decoder、归一化统计 |
| ② MPC | `KoopmanMpcController` + `LatentMpcQpSolver` | OSQP 凸 QP 优化 4 维控制（Tier-1 速度 / Tier-2 位姿） |
| ① ONNX plant | `KoopmanOnnxModel` | **仅**闭环仿真被控对象，不参与优化；可 `KOOPMAN_ENABLE_ONNX=OFF` 切除 |
| ③ 桥接 | `KoopmanMotionMpc` + `MotionKoopmanMpcHelper` | 参考重采样 + 坐标变换，对接实船 ROS 节点 `motion.cpp` |

统一约定：状态 $[x, y, yaw, u, v, r]$（6 维，船体系，x 前 / y 左 / yaw 逆时针为正），控制 $[左油门, 左舵角, 右油门, 右舵角]$（4 维）；盒约束 $u_{min} = [-100, -35, -100, -35]$、$u_{max} = [100, 35, 100, 35]$。

### 2.8.2 Tier-1：潜空间跟踪 QP

**目标函数**（`latent_mpc_qp.cpp:120-163, 215-244`）：

$$J = w_z \|Z(U) - Z_{ref}\|^2 + w_u \|U\|^2 + w_{du} \sum_{k=1}^{N-1} \|\tilde u_k - \tilde u_{k-1}\|^2$$

代入 condensed 形式 $Z = Z_{free} + \Theta U$（$Z_{free} = \Gamma z_0 + \xi$），得标准 QP：

$$\min_U \ \tfrac{1}{2} U^\top P U + q^\top U,\qquad P = 2H,\quad q = 2 w_z\, \Theta^\top (Z_{free} - Z_{ref})$$

Hessian（`buildHessian`，`:120-163`，只计算一次）：

$$H = w_z\, \Theta^\top \Theta + w_u I + w_{du} D^\top D$$

其中 $D$ 为相邻步差分矩阵（$D[row, k \cdot n_u + j] = 1$，$D[row, (k-1) \cdot n_u + j] = -1$）。注意：**增量惩罚只覆盖 $k=1..N-1$ 的内部差分**，不含相对 $u_{prev}$ 的首步差分（首步差分只出现在约束里）。

**参考构造**（`mpc_controller.cpp:75-89`）：$Z_{ref}$ 由参考窗口逐步 $\mathrm{encode}(\mathrm{normalize}(ref[u,v,r]))$ 堆叠，$k$ 步取 `ref_window[min(k, len−1)]`（$k = 0..N-1$）。

**约束**（`latent_mpc_qp.cpp:275-321`）：约束矩阵 $A \in \mathbb{R}^{2 n_u N \times n_u N}$，两组各 $n_u N$ 行：

1. **盒约束**（归一化空间）：$\dfrac{u_{min}[ch] - \mu_{ch}}{\sigma_{ch}} \leq \tilde u_i \leq \dfrac{u_{max}[ch] - \mu_{ch}}{\sigma_{ch}}$；
2. **变化率约束**：
   - $k=0$：$\tilde u_{prev} - \widetilde{du} \leq \tilde u_{0,j} \leq \tilde u_{prev} + \widetilde{du}$，锚定上一拍物理控制 $\tilde u_{prev} = (u_{prev}^{phys} - \mu)/\sigma$；
   - $k \geq 1$：$-\widetilde{du} \leq \tilde u_{k,j} - \tilde u_{k-1,j} \leq \widetilde{du}$，$\widetilde{du} = du_{max}/\sigma$；
   - 通道级 $du_{max}$：通道 0/2（油门）默认 `throttle_du_max=15.0`（%/步），通道 1/3（舵角）默认 `rudder_du_max=3.5`（°/步）；`du_max[j]>0` 可逐通道覆盖；$\leq 0$ 时该行退化为 $\pm 10^{30}$。

**OSQP 调用**（`latent_mpc_qp.cpp:323-383`）：$P$ 稠密对称 → 仅上三角转 CSC；$A$ 稠密 → CSC；设置 `eps_abs=eps_rel=1e-4, max_iter=4000, verbose=0, warm_start=1`；`osqp_setup → osqp_solve`，可 `osqp_warm_start_x` 注入上一拍解；失败抛异常并携带 OSQP status 字符串。OSQP 由 CMake **FetchContent 静态构建**（`osqpstatic`，GIT_TAG **v0.6.3**，`cpp/koopman_control/CMakeLists.txt:31-36`）。

**控制块（move blocking）的实际行为**：QP 决策变量始终是全 horizon $n_u N$ 维；`opt_control_steps`（当前 =2）与 `control_hold_steps` 只在求解**之后**由 `expandToFull` 后处理：前 $n_{opt}$ 步保留，尾部用第 $n_{opt}-1$ 步常值填充，再按 hold 块对齐（`latent_mpc_qp.cpp:165-190, 378-380`）。即文档"优化变量 2×4=8 维"的描述与实现**不一致**——`opt_control_steps` 不减小 QP 规模，仅改变最终采用/评估的控制序列（取舍：实现简单、QP 规模恒定利于时延稳定；代价：尾部代价仍参与优化）。

### 2.8.3 Tier-2：物理位姿 $(x, y, \psi)$ 跟踪

启用条件：`(w_xy>0 || w_yaw>0) && decoder.loaded()`（`mpc_controller.cpp:50-52`；旧版 YAML 无 decoder 节点时静默禁用）。

**非线性位姿预测模型**：位姿由 $\mathrm{decode}(z) \to (u,v,r)$（物理速度，已反归一化）经**半隐式欧拉**积分（沿用"速度 $vel_m$ 配 $yaw_{m-1}$"的 rollout 约定，`pose_linearize.cpp:62-75`）：

$$x_m = x_{m-1} + (u_m \cos\psi_{m-1} - v_m \sin\psi_{m-1})\,dt,\quad y_m = y_{m-1} + (u_m \sin\psi_{m-1} + v_m \cos\psi_{m-1})\,dt,\quad \psi_m = \psi_{m-1} + r_m\,dt$$

**仿射灵敏度 Φ 与偏置 b**（`pose_linearize.cpp:14-136`）：在标称控制序列 $U_0$ 处一阶线性化：$P_{pose} \approx p_{free} + \Phi U$。

1. 标称潜轨迹 $Z_0 = \mathrm{predictStacked}(z_0, U_0)$（精确线性传播）；
2. 每步解码 $d_m = \mathrm{decodePhysical}(z_m^0)$ 与**解析 Jacobian** $J_{p,m} = \partial [u,v,r]_{phys} / \partial z \in \mathbb{R}^{3 \times n_z}$，并 $V_m = J_{p,m} \cdot \Theta_{block}(m) \in \mathbb{R}^{3 \times n_u N}$；
3. 位姿灵敏度递推（$S_x, S_y, S_\psi \in \mathbb{R}^{n_u N}$ 为 $p_m$ 对 $U$ 的行向量偏导，记 $c=\cos\psi, s=\sin\psi$）：

$$
\frac{\partial x_m}{\partial \psi_{m-1}} = (-u_m s - v_m c)\,dt \equiv dx_{d\psi},\qquad
\frac{\partial y_m}{\partial \psi_{m-1}} = (u_m c - v_m s)\,dt \equiv dy_{d\psi}
$$
$$
S_x \leftarrow S_x + dt\,(c\, V_u - s\, V_v) + dx_{d\psi}\, S_\psi,\qquad
S_y \leftarrow S_y + dt\,(s\, V_u + c\, V_v) + dy_{d\psi}\, S_\psi,\qquad
S_\psi \leftarrow S_\psi + dt\, V_r
$$

$$\Phi[3(m-1)..3m-1,\ :] = [S_x;\ S_y;\ S_\psi]$$

4. 偏置 $b = nominal\_err - \Phi U_0$，yaw 分量经 wrapAngle 归一化到 $(-\pi, \pi]$；行权重 $w_q$：x,y 行 $= w_{xy}$，yaw 行 $= w_{yaw}$。

**叠加进 QP（软约束）**（`latent_mpc_qp.cpp:246-273`）：

$$J \mathrel{+}= \sum_r wq_r (\Phi U + b)_r^2 \;\Rightarrow\; P \mathrel{+}= 2 \Phi^\top \mathrm{diag}(wq)\, \Phi,\qquad q \mathrel{+}= 2 \Phi^\top \mathrm{diag}(wq)\, b$$

仍是凸 QP，复用同一 OSQP 管线；位姿只作软约束（代价项），不加硬约束，避免不可行。

**SQP 外迭代**（`mpc_controller.cpp:128-146`）：长 horizon 下单次线性化失效，做 `sqp_iters`（默认 2）次外迭代：标称 $U$ 初值取 warm-start（上一拍解）或零 → `buildPoseLinearization` → OSQP（解同时作为下一次标称与暖启动）→ 更新 $U$。位姿参考 `pose_ref` 取 `ref_window[1..N]` 的 $[x,y,yaw]$（注意与潜参考 $k=0..N-1$ 的索引约定相差一步）。

**decoder 与解析 Jacobian**（`koopman_decoder.cpp`）：decoder 为 Linear+GELU MLP（48→64→64→3）；`decodePhysical` 前向后取前三维并 $h \cdot \sigma_{dyn} + \mu_{dyn}$ 反归一化（`:96-126`）；`jacobianPhysical`（`:128-182`）从 $J = I_{n_z}$ 起逐层累乘——Linear 层 $J \leftarrow W J$，GELU 层 $J \leftarrow \mathrm{diag}(g'(h)) J$，其中 $\mathrm{gelu}'(x) = \tfrac12\big(1 + \mathrm{erf}(x/\sqrt 2)\big) + x\, e^{-x^2/2}/\sqrt{2\pi}$（erf 精确式，与 PyTorch 默认一致）；最终 $J_{phys} = \mathrm{diag}(\sigma_{dyn}) J \in \mathbb{R}^{3 \times n_z}$。

**C++ encoder**（`koopman_encode.cpp`）：$\mathrm{encode}([u,v,r]_{norm}) \to z(48)$ = dict16 原子（含 clamp ±5，`:122-149`）+ `residual_conv_block` 链（conv 权重 $(out,1,3)$ 展平后**只取中间 tap** 作逐通道缩放——单步编码无时间上下文，`:159-171`）+ 末层 Linear → hidden(32)，$z = [atoms(16); hidden(32)]$。

### 2.8.4 控制器主流程与配置

`KoopmanMpcController::solveStep(state0, ref_window, u_prev_applied)`（`mpc_controller.cpp:105-166`）：

```
z0 = encode(normalizeDyn(state0[3:6]))
构造 Z_ref（Tier-1）与可选 pose_ref（Tier-2）
SQP 循环 ×sqp_iters：buildPoseLinearization → LatentMpcQpSolver::solve

```

## 3.3 rosbag 后处理对齐与 npz 数据集格式

### 3.3.1 后处理管线（scripts/data/，三个切分脚本共享同一套逻辑）

以 `split_high_density_bag.py` 为典型：

1. **读包**（`:36-47`）：订阅 `TOPIC_POSE='/localization/fusion_pose'` 与 `TOPIC_THRUSTER='/system/chassis_feedback'`。从 pose 提取 `Pos=[x, y]`、`Vel=[u, v]`（体轴速度）、`pqr=[r]`、`Yaw`；从 feedback 提取 4 维 `Thrusters_CMD`。**注意：控制量取的是 chassis_feedback（执行器反馈），不是 /control/control_cmd 指令**——模型学到的是"实际作用控制→状态"的映射，代价是无法直接分析指令-反馈延迟；
2. **时间对齐**（`:49-52`）：两路时间戳同减 $t_0$，构造公共网格 `t_common = arange(max(首帧), min(末帧), 1/target_hz)`，target_hz = **10 Hz（data_dt = 0.1s）**；
3. **插值**（`:54-59`）：全部用 `scipy.interpolate.interp1d`（线性，`fill_value="extrapolate"`——已知风险：缺口处可造非物理样本，sim-to-real 指南 P0 要求禁止外推）；yaw 先 `np.unwrap` 再插值避免 ±π 跳变；全部转 float32；
4. **切段**（`extract_segments`，`:61-81`）：按时间表 (start,end) 边界取 mask，**丢弃不足 20s 的碎片**；每段字段转置为 (dim, T) 布局；`len = indices[-1]-indices[0]`（切片 `[i0:i1]` 使实际帧数比区间标称少 1 帧，如 200s→1999 帧——无害但已固化的口径）；
5. **保存**：`np.savez_compressed(path, datas=np.array(segs, dtype=object))`——单 key `datas`，object 数组，加载需 `allow_pickle=True`。

脚本间差异：`split_high_density_bag.py` 用 dense 时间表输出 TRAIN/VAL/TEST；`bag_test.py` 用 standard 时间表；`extract_left_turn.py:9-73` 处理单独录的左转补充包（不分 split，按 200s 机械切段，`math.ceil` 保留尾部、阈值放宽到段长 90%）；`merge_npz.py:13-31` 做段级 `concatenate(TRAIN, TRAIN_LEFT_TURN)` → TRAIN_MERGED（不 shuffle，段顺序为"90 段 dense + 9 段左转"，靠 DataLoader shuffle 消解）；`check_dataset.py` 为 QA 可视化工具（按段绘制全变量网格图到 `dataset_plots/`）。

## 3.4 数据增强（v4 噪声增强参数）

定位：P1 工程手段（非 domain randomization 研究），**前提是先完成 P0**（坐标系统一、清洗、重算归一化）——脏数据上增强会放大坏样本（`docs/数据增强技术方案.md`）。

- **覆盖能力判定**：状态噪声（fusion 速度毛刺 → encode 落点漂移）能用 `noise_std` 覆盖；控制噪声（指令量化抖动 → $Bu$ 每步扰动累积）能用 `ctrl_noise_std` 覆盖；归一化漂移**不能**（靠重算 mean/std）；风流/吃水/延迟**不能**（靠 P2 增广或 fine-tune）；开环→闭环分布差**部分缓解**（仍需闭环再训）；
- **参数设计**（§2.2 核心数字）：状态噪声仅对 t0 的归一化 $(u,v,r)$ 加 $\mathcal{N}(0,\sigma)$，`--noise_std 0.02~0.03`；控制噪声对每步归一化 4 维 CMD 加噪，`--ctrl_noise_std 0.003~0.005`；作用域**仅 `model.training=True`**，验证/eval/导出 σ=0；
- **明确不做**：大规模 domain randomization（缺物理仿真闭环）、Mixup/时序扭曲/随机裁剪（破坏动力学一致性与位姿积分监督）、对 GT 目标序列加噪、用增强替代 fine-tune；
- **作业顺序**：P0 清洗 → P1a 源域预训练（可关噪）→ P1b 实船 fine-tune（`0.02/0.003`）→ P1c 关噪对照 run → P1d 无噪 held-out eval → 达标后导出；扫参一次只动一个轴；
- **验收**：held-out 无噪评估，`vel_rmse@1` 不显著变差、`vel_rmse@20` 持平或略好、`traj_xy` 不恶化、`instability_score` 不显著上升；
- 代码落点：`new_v4_dict_input/train_v4_dict_input.py:298-324, 347-348`（`rollout_train` 依 `model.training` 判定）与 `scripts/train_v2.py:357-386`；静态检查 `tests/test_v4_noise_augment.py`。

## 3.5 训练流水线：v1 → v2 → v3 → v3a → v4 的演进

### 3.5.1 v1（`scripts/train_v1.py`，255 行）——历史 baseline

- 数据：`ExplicitKoopmanDataset`（`:50-91`），样本为段内起点全枚举（无 stride），`__getitem__` 内逐样本重组 numpy（低效实现），`num_workers=12`；
- 模型：`HorizontalKoopmanModel(state_dim=3, hidden_dim=24)`（latent=32，5 阶字典）；
- 损失三项（`:168-180`）：**物理加速度 MSE**（反归一化后差分/dt，$w_{acc}=100$，主损失）+ $L_{lin}$（$w=15$）+ $L_{stab}=\mathrm{relu}(\rho-1.01)^2$（$w=0.1$）；
- 优化：Adam(lr=1e-3, wd=1e-4) + StepLR(30, 0.5)，grad-clip 1.0，epochs=150，batch=1024，pred_len=20（无 curriculum）；**选模指标 = 验证加速度损失**；无早停/AMP/EMA/resume/DDP；
- 已知问题：按加速度优化导致速度"形似但漂移"——系统性 bias 随步单调累积，$slope\_loglog \approx 1$。标准化评估复测：v1 基线 `vel_rmse@20=0.02564`、`slope_loglog=0.991`、`instability_score=2.153`、`divergent_sample_pct=99.9%`——近乎全线发散。

### 3.5.2 v2（`scripts/train_v2.py --model v2`）——针对 v1 症结的八项改造

模型类与 v1 相同，差别全部在训练（文件头 docstring `:1-22`）：

1. **主损失改物理速度 Huber**：$L_{vel}$ 见 2.3.2，$\gamma_{step}=0.97$ 步加权 + $1/\sigma$ 通道缩放；
2. 多步 rollout 全程归一化空间，反归一化后对物理量监督；
3. $L_{lin}$ 降权到 1.0 且前 5 epoch ramp-up；
4. encoder dropout 默认 0（防 encode(target)≠rollout 的分布污染）；
5. **Curriculum**：pred_len 4 起每 10 epoch +2 直到 20；
6. 归一化统计一次算完，Dataset 预拼大数组、`__getitem__` 只做整数切片；
7. EMA（decay=0.999）+ CosineAnnealingWarmRestarts($T_0=20, T_{mult}=2$) + AMP；
8. **best ckpt 改由 `vel_rmse_mean`/`composite` 等物理指标决定**。

后续（606fbef）追加三手段，是 9.4 验收 PASS 的关键：

- **$L_{bias}$**：批均值逐步偏置平方惩罚（$\gamma_{bias}=1.05$），直接针对"bias 随 step 单调累积"根因；
- **噪声注入**：t0 状态 + 每步控制高斯噪声（仅训练态）——"打破 slope_loglog==1 的主导杠杆"；
- **谱约束收紧**：推荐 `--rho_max 0.999 --w_stab 5.0`（潜空间轻微收缩）。

**v2 最终成绩**（test，K=20，对比 v1）：`vel_rmse@20` 0.02564→0.01606（−37.4%）、`slope_loglog` 0.9915→0.6695（−32.5%）、`instability_score` 2.153→1.236（−42.6%）、`divergent_sample_pct` 99.88%→81.78%、`traj_xy@20` −27.6%；9.4 条件 A（vel@20 ↓≥30% 且 slope ↓≥20%）、B（instability ↓≥25% 且 vel 不升）同时满足 → PASS。代价是短程退化：`vel_rmse@1` +40.6%（牺牲短程换长程）。遗留：u 通道占 step-20 误差约 98%、$u\_bias=-0.00255$ 线性累积、高速+偏航段误差是低速段 3.5 倍。

### 3.5.3 v3（`--model v3`）——16 阶字典攻 u 通道

- 字典 5→16 atom（见 2.2.3），latent 32→43；ckpt 新增 `model_class/feature_dict_atoms/latent_dim` 三键；YAML 新增 `dictionary` 段；
- per-channel bias 权重 `--w_bias_u/v/r` 取代标量；
- `--w_slope/--slope_target`：log-log 斜率显式惩罚（`train_v2.py:446-467`）；
- eval 端新增 per-segment 聚合与 12 条硬阈值（G1–G5 全局、S1–S4 段间、N1–N3 不准退化）；
- **结果**（10 轮迭代，best=run02）：v3 vs v2——`vel_rmse@20` 0.01606→0.01107（↓31.1%）、u@20 ↓36.1%、|u_bias| 0.00255→0.00038（↓85.2%）、worst/best 比 3.47→2.22、traj_xy@20 ↓29.3%；12 条阈值 **10✅/2❌**（G4 slope=0.712>0.6695、S4 相对 v1 退化样本 23%>20% 未过）；隐性副作用：**v 通道回退 +59%**（16 atom 中含 v 的三次项达 7 项，v 梯度灵敏度过高）。

### 3.5.4 v3a（Plan-A）——不动架构的三件事

任务书规定只做三件事把 12 阈值拉到 14/14：

- **A1**：`--w_bias_v 30→100`（u=80、r=30 不变），专压 v 通道误差；
- **A2**：新选模口径 `composite_v3a`（公式见 2.3.4）+ 离线 ckpt 重选脚本（`scripts/reselect_v3a.py`，不重训）；
- **A3**：per-segment 加权 `WeightedRandomSampler`，$w_{seg} = (u_{std}^2 + 0.5 r_{std}^2 + 10^{-3})^\alpha$（未归一化空间统计），专训高 $u_{std}/r_{std}$ 段；val/test loader 不动防口径污染；段权重 >10× mean 时打 warning；
- 新增 2 条 v 通道保护阈值（V1 `v_rmse@20 ≤ 0.00342`、V2 `|v_bias| ≤ 0.00040`），合成 14 条验收。

**最终交付**（362e610）：采用 A2 离线重选（不重训）从 v3 的 10 个 run 中选出 run05 作为 `koopman_v3a_best`，14 条中 **11✅/3❌**（G4 slope=0.7066、G5 inst=1.2921、S4 deg=26.42%）。v3a vs v3：v@20 0.00452→0.00326（A1 达标）、|u_bias| 3.8e-4→3.9e-6（几乎零漂移）、S2 2.22→1.80。**结构性结论**："Koopman + 线性外推 $(I+A)^k z_0$（谱半径≈0.998）架构在该数据集上 slope 下界≈0.70"，A3 强采样与 G4/G5 构成结构性 dilemma——要突破必须走非线性 latent step 或换建模范式。这是 v4 立项的直接动因。

### 3.5.5 v4（`new_v4_dict_input/train_v4_dict_input.py`，1255 行）——当前主线

模型结构变化见 2.2.4（dict16 主输入、去状态直通、decoder MLP、latent=48）。训练机制：

- **数据**：`KoopmanVoyageDataset`（`:154-221`）复用 `ek._flatten_segments`；`model_stride = dt/data_dt` 下采样；归一化统计训练集计算；
- **损失**（`:327-411`）：见 2.3.2（v4 版：无 $L_{bias}/L_{slope}$，$L_{recon}$ 必需 0.5，新增 $L_{xy}/L_{yaw}$ 位姿损失）；
- **优化**：AdamW(lr=1e-3, wd=1e-4)，grad-clip 1.0，EMA decay=0.999（验证/best 用 EMA 权重）；
- **Curriculum**：`pred_len = min(max, start + step·(epoch//grow_every))`，默认 start=2 步、每 5 epoch +2、max 由 `pred_time_sec/dt` 决定；扩窗重建 Dataset/DataLoader；
- **调度器**：`warmrestart`（历史默认 $T_0=1000$，常规 epoch 内 LR 几乎恒定——名不副实）/ `cosine` / **`cosine_warmup`（推荐：LinearLR warmup 5 epoch + cosine 到 lr_min=1e-5）** / `constant`；
- **DDP**：`V4LossModule`（`:414-443`）把整个损失包进 `forward`——修复了"DDP 不转发 `encode` 等自定义方法且绕过 reducer"的历史 bug；梯度累积非步进 micro-batch 用 `no_sync()` 跳 all-reduce；支持 gloo CPU DDP 冒烟；
- **AMP**：`--amp`（仅 CUDA）+ GradScaler，与梯度累积兼容；
- **断点续训**：`--resume` 恢复 model/optimizer/scheduler/EMA/scaler/epoch/best_metric 全套状态；
- **早停**：`--early_stop_patience N`，仅在 curriculum 到达 pred_len_max 后计数，rank0 判定后广播；
- **噪声增强**：`--noise_std/--ctrl_noise_std`（见 3.4）；
- **best 选择**：composite = `test/vel_rmse_mean × max(1, instability_score)`；每 epoch 存 latest，末 30 epoch 每 5 epoch 存周期 ckpt；
- **训练结束**（仅 rank0）：导出 `koopman_v4_best.yaml`（注意：仅 system_matrices 简表，**不能喂 C++ MPC**）+ 自动 test 集评估出图；`--smoketest` 用迷你数据集 2 epoch 校验三件产物；
- **多卡**：`run_v4_ddp.sh`（torchrun，NPROC≤1 退化单进程）；`run_v4_in_docker.sh` 在容器 `koopman_latest_sm120_martin` 中运行；README 给出 8GB 显存推荐配置（batch 512 × accum 2 = 等效 1024）。

**dt=4s / 10-step 训练**（`configs/v4_dt4s_train.yaml` / `v4_dt4s_10step_train.yaml`）：

- 动机：在**相同预测物理时长（20s）**下，dt=4s 把 200 步 rollout 压到 5 步，降低误差累积与 MPC 计算量；
- `v4_dt4s_train.yaml`：dt=4.0（model_stride=40）、pred_time 20s（pred_len_max=5）、120 epoch、batch 512×accum2、hidden 32、w_recon 0.5、ckpt_dir=`checkpoints/v4_dt4s`；
- `v4_dt4s_10step_train.yaml`：自 5 步 best ckpt `--resume` 续训，pred_len_max=10（40s 时长）、240 epoch；
- `run_v4_dt4s.sh`：一键"训练 → 找最新 run 的 best → 推断 pred_len → eval（--dt 4.0）"；`compare_dt4s_vs_original.py` 输出 dt=1s vs dt=4s 的 Markdown 对比表与 RMSE-时间曲线。

### 3.5.6 v4 baseline vs 优化对照实验结论（`docs/工程分析与优化.md` §4-§5bis）

**2×2 消融**（同一公共配置、seed=42、各 120 epoch，用 `compare_runs_v4.py` 正确传 model_stride=10 评估）：

| 配置 | scheduler | encoder | vel_rmse_mean | vel@1 | vel@20 | u@20 | v@20 | r@20 | traj_xy@20 |
|---|---|---|---|---|---|---|---|---|---|
| baseline | warmrestart | conv | 0.03403 | 0.03568 | 0.05107 | 0.04480 | 0.02451 | 0.002349 | 0.7597 |
| 消融 A | cosine_warmup | conv | 0.03509 | 0.03207 | 0.05806 | 0.05131 | 0.02717 | 0.002281 | 0.7282 |
| 消融 B | warmrestart | mlp | 0.03065 | 0.02989 | 0.05141 | 0.04305 | 0.02809 | 0.001938 | 0.6829 |
| optimized | cosine_warmup | mlp | **0.03014** | **0.02412** | **0.04862** | **0.03908** | 0.02893 | **0.001845** | **0.6666** |

- optimized 相对 baseline：`vel_rmse_mean ↓11.4%`、`vel@1 ↓32.4%`、`u@20 ↓12.8%`、`r@20 ↓21.4%`、`traj_xy@20 ↓12.3%`；唯一退化 `v@20 ↑18.0%`；
- 结论：**encoder=mlp 是主要收益来源**；cosine_warmup 的作用依赖 encoder（配 conv 反而略差，配 mlp 再降短程与长程）；
- `slope_loglog/instability_score` 略升是"vel@1 大降使末/首比值变大"的口径效应，并非真发散。

**第二轮优化（针对 step10-20 误差单调上升）**：

- 失败项诚实记录：`rho_max 0.999 + w_stab 0.5` 虽把 $\rho$ 压到 0.9993<1，但 K=20 曲线几乎不变——**长程增长来自控制序列驱动的开环预测误差累积，而非数值发散**；`gamma_step 1.05 + w_lin 3.0` 反而抬高短程；
- **真正有效：hidden_dim 32→64（cap64，latent 48→80）**：vel_rmse_mean 0.03014→**0.02804**（↓7%）、v@20 0.0289→0.0250（修复第一轮 v 退化）、ratio@20/1 2.02→1.78、slope_loglog 0.189→0.150；
- 取舍：精度优先选 cap64（代价：latent 48→80 需重新导出 ONNX/YAML 并更新 C++ 维度）；须保 latent=48 接口则用第一轮 optimized。

**训练性能工程优化 7 项**（行为保持，`docs/训练流程指南.md` §6）：① 验证 rollout 取数改 numpy fancy-indexing gather（v1 K=20、35622 窗口 0.631s→0.179s，3.5×）；② device→host 小拷贝合并；③ npz 扁平化模块级缓存（curriculum 9 次重建 0.388s→0.048s，8×）；④ train_v2 验证去重（degraded_pct 复用同次 rollout，验证耗时减半）；⑤ v4 每 epoch 验证 loss 子采样（2.02s→0.05s/epoch，~40×）；⑥ v4 DDP `no_sync()`；⑦ `torch.cuda.amp`→`torch.amp` 新 API。数值等价由 `tests/test_rollout_equivalence.py` 逐位对比保障。

## 3.6 评估体系（koopman/evalkit.py）

### 3.6.1 设计原则与 rollout 协议

文件头注释（`evalkit.py:5-11`）阐明三条原则：**物理空间评估**（所有 RMSE/MAE/R²/bias 在反归一化物理量上计算）、**机器可读优先**（CSV/JSON/MD 先落盘再画图）、**发散指标**（定量回答"误差是否随步数发散"）。

`rollout_dataset`（`:208-310`）无 teacher-forcing 多步预测：$z = \mathrm{encode}((x_0[3{:}6]-\mu)/\sigma)$，每步 $z \leftarrow \mathrm{latent\_step}(z, u_k)$、$\hat x^{phys} = \mathrm{reconstruct}(z)\cdot\sigma + \mu$；位置用预测与 GT 速度各做一套欧拉积分（初值同为 GT 起始位姿）。关键约定：第 k 个模型步的控制与状态取自原始数据 `t0 + k*ms` 行，GT 速度取 `t0 + (k+1)*ms` 行；**GT 轨迹不是记录的真实位置，而是用 GT 速度重积分**——`traj_xy_err` 只度量速度误差的积分效应，不反映绝对定位精度。

### 3.6.2 指标族

- **逐步指标**（`compute_per_step_metrics`，`:343-392`）：`vel_rmse/mae/p50/p90/p99`（水平速度误差 $\sqrt{\Delta u^2+\Delta v^2}$，不含 r）、每通道 rmse/bias/nrmse/R²/corr、`acc_rmse`、`traj_xy_err`；
- **发散指标**（`:395-447`）：见 2.1.3 表；
- **summary**（`build_summary_dict`，`:583-647`）：aggregate / divergence（含 `divergent_sample_pct` = 单样本 ratio>5 的占比）/ channel_bias / tail（P50/P90/P99/max）/ fit_quality；
- **per-segment 聚合**（`:909-976`）：按 `seg_idx` 分组；**口径警示**：per-segment 的 `vel_rmse_{1,5,10,K}` 故意用 mean(vel_horiz_err) 而非 RMS（对齐历史 baseline 与绝对阈值），与全局 per-step 的 RMS 口径不同，读数不可混用；段内原始统计含 `u_mean/u_std/v_std/r_std/dthr_mean`（dthr_mean 表征差速强度）；
- **阈值验收**：`V3_THRESHOLDS`（`:1472-1488`，12 条：G1 `vel@K≤0.01285`、G2 `u@K≤0.01185`、G3 `|u_bias|≤0.00153`、G4 `slope≤0.6695`、G5 `inst≤1.2363`、S1 `worst≤0.01569`、S2 `ratio≤2.78`、S3 `high_speed≤0.01144`、S4 `degraded≤20%`、N1 `vel@1≤0.00240`、N2 `traj≤0.02108`、N3 `ρ≤1.005`）+ `V3A_EXTRA_THRESHOLDS`（V1/V2 两条 v 通道保护）；
- **9.4 硬性验收**（`_compare_verdict_text`，`:1331-1353`）：条件 A = `vel_rmse@K` 降 ≥30% 且 `slope_loglog` 降 ≥20%；条件 B = `instability_score` 降 ≥25% 且 vel 不升；A∨B 判 PASS/FAIL；
- **产物**：`evaluate_one`（`:1040-1141`）落盘 per-step CSV/MD、per-sample CSV、per-segment CSV/MD、summary.json、6 张 PNG；`--compare` 多 ckpt 对比；`--smoketest` 断言 10 个产物文件齐全。

### 3.6.3 模型装载与口径陷阱

`load_model_from_ckpt`（`:831-866`）按 `ckpt['model_class']` dispatch（v4 → hidden_dim/clamp_pif/encoder_arch 取自 ckpt 内嵌 args；v3 → hidden 24、n_cubic 11；v1/v2 → 硬编码 hidden_dim=24）；优先 `ema_state_dict`，加载后强制 Dropout.p=0。**已知口径陷阱**：`scripts/eval.py --compare` 不传 `model_stride`，对 v4(dt=1.0) 会错误地按 0.1s 步长 rollout——v4 对比必须用 `new_v4_dict_input/compare_runs_v4.py`。

## 3.8 导出：ONNX 与潜空间权重 YAML

v4 ckpt 有两条导出链路，**分工明确**（`ONNX导出说明.md:3-5`）：OSQP-MPC 优化读 latent YAML；ONNX 仅作闭环仿真 plant。两者须由同一 best ckpt 导出保持同源。

### 3.8.1 潜空间权重导出（`new_v4_dict_input/export_v4_encode_weights.py`，MPC 优化用）

同时写 JSON 与 YAML（默认 `cpp/koopman_mpc/weights/koopman_v4_latent.{json,yaml}`），内容（`:109-138`）：

- `normalization`：`dyn_mean/std`（state stats 的 [3:6]）、`ctrl_mean/std`；
- `koopman`：**Ā = A.weight + I**（`:105`，与 latent_step 残差形式对应）、`bias=A.bias`、`B=B.weight`，供 C++ OSQP 构造 $z_{k+1}=\bar A z_k + b + \bar B u_k$ 的 QP；
- `encoder`：按 forward 顺序导出 `res_mlp` 各块（`residual_conv_block` 的 fc/conv_weight/conv_bias/shortcut，或 `linear`）；C++ 侧复现 atoms16（含 clamp）+ encoder 前向以从 $(u,v,r)$ 得 $z_0$；
- `decoder`：`Linear/GELU` 逐层导出（`:54-67`），供 C++ Tier-2 位姿跟踪做 $z(48) \to (u,v,r)$ 线性化；
- 元信息：`latent_dim=48`、`control_dim=4`、`dict_dim=16`、`clamp_pif`、`encoder_arch`、`horizon_default`、`dt`（写入供 C++ 验证工具读取）。

注意：仅支持 `encoder_arch=conv` 的 ckpt 导出（`--horizon` 须与 mpc_config 一致）。

### 3.8.2 ONNX 导出（`new_v4_dict_input/export_v4_onnx.py`，闭环仿真 plant 用）

- 模型封装为 `KoopmanRollout(model, stats)`（`koopman/export/rollout.py:12-55`）：归一化 buffer 内嵌，forward 为 `state0(6,) → encode → H 步 latent_step+decode → 每步船体系欧拉积分 → states(H+1, 6)`；
- ONNX 接口（`:63-76`，opset=18，旧式 tracer `dynamo=False`）：输入 `state0 (6,)`、`u_seq (pred_len, 4)`、`dt` 标量；输出 `states (pred_len+1, 6)`；**horizon 在导出时固定**（`--pred_len`），须与 C++ `mpc_config.yaml` 的 `horizon` 一致；
- 只允许 `model_class == HorizontalKoopmanModelV4DictInput` 的 ckpt；
- **两级验证**：随机用例（1 零输入 + 8 随机输入，PT vs ONNXRuntime 最大误差 ≤ atol/rtol≈1e-4，否则 raise）+ test 集对比（默认 512 样本等距子采样，逐步 per-channel rmse/mae/max_abs CSV + summary JSON，`passed = max_err ≤ 1e-3` 仅告警不阻断 + 9 张对比图）；
- `model_meta.json`：model_class、input_mode="dict16_only"、字典元信息、dt/data_dt/model_stride/horizon_default、两级验证误差、`u_min/u_max=[±100,±35,±100,±35]`、归一化统计量；
- `--write_rollout_check` 额外写 `rollout_check.npz`（固定 $s_0=[0,0,0,1.5,0,0]$、$u=0$ 的参考轨迹），供 C++ `verify_rollout` 对照。

**horizon 双口径易混**：训练 pred_len 以"模型步"计（dt=1s 时 20 步=20s；dt=4s 时 5 步=20s），而 ONNX 部署的 pred_len=200 是 0.1s 仿真步口径；需按 dt 换算。

### 3.8.3 benchmark（`benchmark_v4_onnx.py`）

provider auto/cpu/cuda（auto 优先 CUDAExecutionProvider）；warmup 50 次 + 1000 次 `time.perf_counter` 单次全 rollout（H 步一次性推理）计时；统计 mean/std/min/max/median/p90/p95/p99 与 throughput_fps；报告 JSON 写 `eval_out/v4_onnx_benchmark/`。

### 3.9.3 motion 桥接与实船集成

**桥接层 `KoopmanMotionMpc`**（`cpp/koopman_control/src/motion_bridge.cpp`）：

- `MotionSolveInput`：当前船体速度 $\{u,v,r\}$、`u_prev/has_u_prev`、`ref`（`MotionRefPoint{x,y,psi,u,v,r}` 序列）、Tier-2 用的当前全局位姿 $\{x,y,psi,has\_pose\}$；
- **参考重采样**（`resampleMotionRefToHorizon`，`:58-78`）：motion 侧 N 个点按时间轴 $t = ref\_time\_offset + i \cdot ref\_dt$（默认 $0.5 + i\cdot1.0$，对应 `PointChange` 的 `i*mpc_during+0.5`）线性插值到 MPC 时间轴 $t_k = k\cdot dt$（$k=0..horizon$），两端 clamp；
- **坐标变换**（`buildRefWindow`，`:150-170`）：`has_pose=true` 时把全局参考变换到"当前船位为原点、当前艏向为 x 轴"的船体系：$p_{body} = R(-\psi)(p_{global} - p_{cur})$，yaw 取相对并 wrap；速度分量不变（已是船体系参考量）；
- `solve`：$state0 = [0,0,0,u,v,r]$ → `solveStep` → 每次求解 printf 计时（total/ref_resample/qp_solve/osqp_iters/status/cost）。

**胶水层 `motion_koopman_mpc.cpp/.hpp`**（拷贝到 ship_control）：仅在 `USE_KOOPMAN_MPC` 宏下编译；`init(yaml_path, onnx_path, mpc_during)` 中 onnx_path **被忽略**（OSQP 路径无需 ONNX）；`solveStep` 填 `MotionSolveInput` 时 `p.r=0`，**未填 `x,y,psi/has_pose`**——当前集成不做桥接层坐标变换，依赖 `PointChange` 已产出船体系参考。

**实船节点 `motion.cpp`**（Elane ROS 控制节点，703 行）：

- 订阅 `/planning/trajectory`、`/localization/fusion_pose`、`/state/controller_state`、`/system/chassis_feedback`、`/draught_observation_results_topic`；发布 `/control/control_cmd`、`/control/debug_msg`；**定时器 0.5 s（2 Hz）**触发 `Run()`；
- `MpcTaRunKoopman()`（`:431-501`）：`PointChange()` 生成船体系参考序列（时间轴 `i*mpc_during+0.5`）→ 转 `MotionMpcTargetView` → `koopman_mpc_helper_.solveStep(u, v, r, targets, out)` → 失败则 `Stop()`；

### 3.9.4 闭环仿真（ONNX plant）

- ONNX plant 接口：`state0(6) + u_seq(H,4) + dt → states(H+1,6)`；单线程、图优化全开；horizon 从 `u_seq` shape 读取；
- **单步推进技巧**（`mpc_controller.cpp:16-33`）：ONNX 图固定 H 步 rollout，闭环仿真只需 `states[1]`，故 `u_seq` 全部填充当前 $u_0$（`states[1]` 只依赖 `u_seq[0]`，填充值不影响）；
- `simulate()`（`:168-221`）：需 ONNX plant 构造（双参构造函数同时校验 ONNX horizon == MPC horizon）；`ref_stride = round(dt/data_dt)`（dt=4.0 → 40），按 stride 从全长参考轨迹取 horizon+1 窗口；可选 `ref_ctrl` 初始化 warm start；每步 `solveStep` → 记录控制/代价 → `rolloutOneStepOnnx` 推进 plant；
- `computeMetrics`（`:228-254`）：xy RMSE/max、yaw RMSE（wrap 后）、末端误差；
- **注意**：`simulate()`/demo 的 plant 仍是 ONNX 模型自身（理想模型闭环），非真实船舶/仿真器；且 simulate 中 `u_prev_applied` 传 `nullptr`，首步速率约束锚定物理 0 控制。

## 3.10 仿真到实船（sim-to-real）P0–P3 清单要点

`docs/仿真到实船优化指南.md`（519 行）是切换新船/装载/水域时的权威清单。核心原则："先开环 eval 过关，再上 MPC；不要直接拿仿真 ckpt 上实船"。

- **P0 数据与坐标系（必做）**：统一坐标系（bag→NPZ 阶段做与 `motion.cpp` 相同的旋转中心变换）；插值禁止外推、缺口 >0.5s 丢窗/丢段；执行器对齐（优先用实际反馈）；工况覆盖（补自由航行、顶风/顺流、不同吃水；MPC 闭环日志单独成集供再训）；质量门控（过滤速度跳变/定位发散/长饱和/时间戳乱序/段长 <20s）；
- **P0/P1 归一化**：必须重算——C++ 侧 normalize 依赖 ckpt/YAML 内同一组统计，仿真与实船航速均值、油门分布差异大（部署 YAML 中常见油门均值约 47%），直接复用导致 encoder 输入尺度错误。**禁止**只换权重不换归一化、或混用 A 船统计 + B 船权重；
- **P1 训练策略**：仿真/源域预训练 → 实船 fine-tune（LR 降为 1/5~1/10；解冻策略优先 decoder 与 B，数据量够再解冻 encoder/A）；v4 噪声增强（0.02~0.03 / 0.003~0.005）；相对提高 v/r 通道权重；`rho_max` 略收紧至 ≤1.0 附近；除 K=20 外看 K=40/60 长程 eval；MPC 采数后追加闭环再训（DAgger 思路）；
- **P2 模型与执行器扩展**：输入延迟（时间对齐或延迟指令作额外输入）、慢变偏置 d（增广状态或在线观测器）、吃水/装载（条件输入/分工况模型，`motion.cpp` 已订阅读水可接）、dt 与 ZOH 假设复核、`clamp_pif` 饱和复核；增广会改 latent/输入维度，需同步改 C++ encoder/MPC 接口；
- **P2 MPC 联合标定**：控制周期 vs 模型 dt（motion 约 0.5s，模型 dt 1~4s 时明确 ZOH 是否成立）；实船先加大 `w_du` 抑抖再放开跟踪；`u_min/u_max, throttle_du_max` 与实船物理限幅一致；**先 Tier-1 跑稳速度层再开 Tier-2**；暖启动保持上一拍 QP 解；
- **P3 在线层与安全回退**（当前仓库无在线自适应模块，中长期规划）：残差观测器（在线估慢变 d 补偿风流）、短窗自适应、健康监控（预测 vs 实测残差超阈记录）、安全回退（残差或求解失败切备用控制器，回退 PID/AD-MPC）。

### 6.1.2 稳定性保证与长时域 rollout 误差累积的改进方法

**稳定化训练（谱约束的升级版）**：

- **DISKO**（Mamakoukas et al. 2020）：[arXiv:2005.04291](https://arxiv.org/abs/2005.04291)——推导任意步 Koopman 预测误差公式，证明约束特征值 $|\lambda| \leq 1$ 改善长时域精度；在最小二乘解基础上求**最近稳定矩阵**（SOC 算法）。本工程 $L_{stab}$ 软惩罚（`train_v4_dict_input.py:385-386`）正是这一思想的松弛版，可升级为训练后投影；
- **EDMD-AS / TEDMD-AS（2025）**：[arXiv:2408.16846](https://arxiv.org/html/2408.16846v1)——带输入 EDMD 回归中直接施加渐近稳定约束；数值显示无约束 EDMD 经常学出不稳定模型；
- **耗散/斜对称参数化（Hankel DMD）**：[arXiv:2408.06607](https://arxiv.org/html/2408.06607v5)——连续时间生成器参数化为**斜对称矩阵 + 负实对角元**，结构上保证稳定（前向/反向都不发散）；配合 progressive rollout 与 Hankel 时延观测量抗噪；
- **谱块参数化（Koopman Dreamer, 2026）**：[arXiv:2607.19719](https://arxiv.org/html/2607.19719v1)——用 2×2 旋转-缩放块组成 A，每块模长显式有界（tanh 压缩到 $\rho_{max}$），参数化层面硬约束谱半径，免调 $w_{stab}/\rho_{max}$；
- **SVD 正则（2024）**：[arXiv:2408.11303](https://arxiv.org/pdf/2408.11303)——对 A 做 SVD 并加奇异值损失使特征值贴近单位圆，配合后向预测一致性。

**长时域误差累积**：

- **多步 EDMD / 直接辨识 condensed 矩阵（MIT, 2026）**：[arXiv:2601.11901](https://arxiv.org/html/2601.11901v1)——**核心结论与本工程直接相关**：单步模型的 k 步预测误差上界含放大因子 $\|A\|^k$（$\rho(A)>1$ 时指数放大）；而**直接学习多步状态-控制映射矩阵 E, F**（即 MPC condensed QP 中 $X = E \psi(x_0) + F U$ 的那两个矩阵）是最小二乘凸问题，误差不累积，还可对 E 加逐行 ℓ1 正则自动剪枝字典。本工程 MPC 正是 condensed QP，该方法等于"跳过 A 的 k 次幂、直接学 Θ"——注意本工程 `rho_max=1.005` 恰好允许 $\rho(A)>1$ 的危险区间；
- **前向-后向一致性（ConsKAE, ICML 2020）**：[Azencot et al.](https://proceedings.mlr.press/v119/azencot20a/azencot20a.pdf)——同时学前向算子 C 与后向算子 D，加 $CD \approx I$、$DC \approx I$ 一致性损失，显著改善长期预测并抑制噪声；只需在 `compute_losses` 加一项，与现有 $L_{lin}$ 并列；
- **连续时间 Koopman（2026）**：[arXiv:2602.02832](https://arxiv.org/html/2602.02832v2)——学线性生成器 L 而非固定步长算子，$z(t+\Delta) = e^{L\Delta} z(t)$，闭式解免迭代积分、可按物理参数条件化；**对本工程价值**：MPC dt=4.0s 而数据 data_dt=0.1s，生成器形式天然支持多步长/变步长训练与部署。

**鲁棒 MPC / 闭环稳定性**：

- **S-KMPC 局部指数稳定（Cortés & Zheng 2025）**：[arXiv:2511.02008](https://arxiv.org/html/2511.02008v1)——① 无模型误差时潜空间 LQR 是原非线性系统的全局最优；② 提升函数 Lipschitz + 单步误差足够小 ⇒ 闭环局部指数稳定；③ **终端代价设计**：解潜空间 LQR 得增益 K，再解 Lyapunov 方程 $A_K^\top \hat P A_K - \hat P + \hat Q = 0$，终端代价 $V_f(z) = z^\top \hat P z$，终端集取次水平集。全部是潜空间线性代数，**叠加到 QP 只是改 P/q 矩阵**——当前 `mpc_config.yaml` 只有 `w_z/w_u/w_du`，无终端项，这是性价比最高的一步；
- **Tube/约束收紧**：[混合随机-确定管 Koopman MPC（2025）](https://arxiv.org/html/2510.21308v1)（Wasserstein DRO 机会约束 + 最坏情况建模误差收紧，QP 可解，保递归可行）；Mamakoukas et al. 2022（估计模型误差 Lipschitz 常数构造保守代理约束）。对本工程：在 hold-out 集上统计单步潜空间预测误差分位数，按比例收紧 `u_min/u_max` 与速率约束；
- **双线性 Koopman 更适合控制仿射系统**：[arXiv:2010.09961](https://arxiv.org/pdf/2010.09961.pdf)（控制仿射系统存在无限维双线性实现但一般不存在有限维线性实现；K-BMPC 精度≈NMPC、耗时≈线性 MPC）；[车辆双线性 Koopman](https://arxiv.org/abs/2507.12578)（horizon 首步冻结控制仿射项化为线性）。**船舶舵力 ∝ U²δ、推进力与转速耦合，控制仿射特性强，是双线性的天然适用对象**——可引入低秩双线性项 $z^+ = z + Az + Bu + \sum_i u_i N_i z$（$N_i$ 低秩），与现有 SQP 外迭代天然兼容。

**潜空间状态估计**：[K-ESKF 四旋翼误差状态卡尔曼](https://www.vodafone-chair.org/pbls/ketong-zheng/Data-Driven_Koopman_Operator-Based_Error-State_Kalman_Filter_for_Enhanced_State_Estimation_of_Quadrotors_in_Agile_Flight.pdf)、[Deep-Koopman 增强 KF（Boscariol 2025）](https://link.springer.com/article/10.1007/s11044-025-10108-7)——因 lifted 系统是线性的，可直接用线性 KF/Luenberger，比 EKF 更稳；对本工程：用 $(\bar A, \bar B, C=[I\ 0])$ 在 lifted 空间跑线性 KF 替代/对照现有物理空间方案。

## 6.3 主题 (c)：实时 MPC 求解器/部署与 RL-MPC 混合

### 6.3.1 Koopman-MPC 实时实现的共识

Korda & Mezić（Automatica 2018，[arXiv:1611.03537](https://arxiv.org/pdf/1611.03537)）确立的路线：EDMD 提升后得线性预测器，MPC 退化为凸 QP，与 NMPC 同精度但快数个量级——本工程正是该路线的深度字典版。共识：**实时性来自"把 NMPC 变成参数化凸 QP"，求解器层的热启动、codegen、结构利用才是毫秒级的决定性因素**。未找到与本工程完全同构（"深度 Koopman 潜空间 + OSQP condensed QP + 船舶速度跟踪"）的公开发表系统；最近同类（AUV Koopman MPC arXiv:2503.09628、Adaptive Koopman+OSQP [arXiv:2405.09101](https://arxiv.org/html/2405.09101v1)）均停留在仿真/Gazebo 层面，**本工程的实船 OSQP 部署在公开文献中属较前沿位置**。

### 6.3.2 QP 求解器谱系与选型结论

实时 QP 求解器分四族（综述：[Real-Time QP Solvers, arXiv:2510.21773](https://arxiv.org/html/2510.21773v1)）：

- **积极集**：qpOASES/qpmad/Eiquadprog——小稠密 QP 上最快、热启动最强（qpOASES online active-set 同伦复用活跃集）；
- **内点法**：HPIPM/CVXGEN/FORCES——迭代少而贵、精度高，HPIPM 利用 OCP 块结构，长 horizon 最优；
- **算子分裂（ADMM）**：OSQP/SCS——单次迭代便宜、可 warm start、**支持早停（次优但可用）与 time_limit**，鲁棒易调；高精度要求下迭代数上升；
- **增广拉格朗日**：ProxQP/QPALM——兼顾速度与精度、能优雅处理不可行。

本工程的 40 变量/80 约束 condensed QP 正落在小稠密 QP 甜区（qpmad/qpOASES 亚毫秒）；若 cap64（latent=80，Θ 变 800×40）或更长 horizon 上线，应考虑块稀疏 OCP 形式交给 HPIPM/ACADOS。

**嵌入式部署标杆**（NTNU/ABB，qpOASES 作者参与）：[Kufoalor et al., ECC 2015](https://torarnj.folk.ntnu.no/ECC15_0291_FI.pdf)——400 MHz PLC 上 condensed 小 QP + qpOASES 热启动比定制内点快 4–6 倍；工程要点：全部静态内存、单精度足够、**move blocking** 压缩决策变量、CV 约束用 exact-penalty slack 杜绝不可行、**常量矩阵离线预计算、在线只更新参数向量**、每步末尾 time shift。

**OSQP 官方 codegen**（[osqp.org/docs/codegen](https://osqp.org/docs/codegen/index.html)）：可生成 malloc-free 专用 C 求解器；`OSQP_EMBEDDED_MODE=1` 视 q/l/u 为在线参数（对应本工程 Tier-1），`=2` 连 P/A 数值也可在线更新（对应 Tier-2 但稀疏模式固定）。**TinyMPC**（[arXiv:2310.16985](https://ar5iv.labs.arxiv.org/html/2310.16985)）：面向 MCU 的 ADMM 求解器，下沉 ARM/MCU 时比 OSQP 更省内存。实时性参照：iRonCub 人形机器人用 OSQP 在 200 Hz 周期平均 2.18 ms（[arXiv:2505.16478](https://arxiv.org/pdf/2505.16478)）——本工程 0.5–1 s 控制周期对求解时间非常宽裕，**瓶颈不在算力而在工程稳健性**。

### 6.3.3 针对本工程 C++ 实现的求解器级改进（按风险分级）

**A 级：纯求解器工程（低风险、收益立竿见影）**：

1. **复用 OSQP workspace，消除每步 KKT 分解**。现状：每次 `solve()` 都 `osqp_setup→solve→cleanup`（`latent_mpc_qp.cpp:348-376`），但 Tier-1 下 P 恒定（`buildHessian` 只算一次），每周期只有 q 与首行速率约束的 l/u 变化。改造：构造期 setup 一次，之后 `osqp_update_q()` + `osqp_update_bounds()`；Tier-2 时把 `denseUpperTriToCsc` 改为无条件保留全部上三角元素，即可用 `osqp_update_P` 原位更新数值。依据：OSQP codegen 文档对 "vectors/matrices as parameters" 的官方划分与 ECC15"离线预计算常量矩阵"；
2. **热启动时移 + 对偶热启动**。现状：直接复用上一周期完整解、不做时移、只 warm-start 原始变量 x（`mpc_controller.cpp:149-150`）。改造：$u_{warm} \leftarrow [U[1..N-1], U[N-1]]$（左移一步、末步重复），并用 `osqp_warm_start()` 同时注入对偶 y；注意时移应在 `expandToFull` 截断**之前**的完整解上做；
3. **实时兜底：`time_limit` + 失败降级而非抛异常**。现状：未设 `time_limit`，OSQP 非 0 状态直接 `throw`（`latent_mpc_qp.cpp:368-372`），实船闭环中一次超时/不可行就会打断控制。改造：`time_limit = 0.5×控制周期`；`max_iter_reached` 时仍取当前迭代点（一阶法中间迭代可用）；彻底失败时降级为"保持 $u_{prev}$"并上报 status；
4. **求解器参数精调**：`polish=1`（小 QP 上代价极低）、eps_abs/rel 从 1e-4 放宽到 1e-3 对比迭代数分布——文献共识 OSQP 在中等精度下最强；以 `osqp_iters` 的**最坏值**评估（HIL 惯例用 worst-case 不用均值）。

**B 级：QP 结构与代价设计（中风险）**：

1. **真 move blocking**：现状 `opt_control_steps=2` 是求解后截断（QP 仍优化全部 40 个变量再覆盖尾部）——浪费 80% 决策变量且解非原问题最优。改造：决策变量直接定义为 $n_u \times 2$ 块序列（Θ 列按块求和压缩为 $\Theta_{blk} \in \mathbb{R}^{480 \times 8}$），nvar 40→8；依据：ECC15 的 move blocking 是工业 MPC 标准配置；
2. **offset-free 扰动通道**：潜空间增广恒定扰动 $d$，$z_{k+1} = \bar A z_k + \bar B \tilde u_k + b + \hat d$，$\hat d$ 由 $\mathrm{decode}(z_k) - (u,v,r)_{测量}$ 残差经低通更新——实现上只改 $\xi \to \xi + \hat d_{累积}$，即只改 QP 的 q，零结构改动。依据：ECC15 的恒扰动项 $V(k0)$、[velocity-form MPC ASV (IEEE JOE 2025)](https://strathprints.strath.ac.uk/91702/1/Jomoh-Yue-IEEEJOE-2025-A-velocity-form-model-predictive-control-of-an-autonomous.pdf)、[arXiv:2312.11409](https://arxiv.org/html/2312.11409v1)；
3. **终端代价/终端权重**：给末 1–2 步 $w_z$ 加权，或按 S-KMPC 离线解 Riccati→Lyapunov 得 $\hat P$ 挂 $V_f = z_N^\top \hat P z_N$（仍凸 QP）；对 $\rho(I+A)=1.0016>1$ 的模型尤其有意义；
4. **参考轨迹参数化与整形**：现状是时间参数化参考（`motion_bridge.cpp:58-78`）——船舶文献共识 path following 不强制时间对齐，比 trajectory tracking 更安全（受扰落后时不会"追赶时刻表"导致切弯/激进）。改造：(a) motion 层把参考改为几何路径 + 沿程速度剖面（LOS：$\chi_d = \chi_p + \mathrm{atan}(-y_e/\Delta)$，横向误差驱动艏向参考；见 [MDPI JMSE 2321](https://www.mdpi.com/2077-1312/12/12/2321)、[Miller 2023](https://bibliotekanauki.pl/articles/27311431.pdf)）；(b) 对时间参考做动力学可行预滤波（速率/加速度限幅斜坡整形）。

### 6.3.4 船舶跟踪 MPC 调参经验

- **预测时域**：覆盖被控量主导时间常数（船舶艏向/速度响应 5–40 s）；本工程 10×4s=40s 对低速船合理；经验法则"N·Δt ≥ 闭环上升时间+执行器延迟，过长 horizon 使迭代数线性增长"（[acados 调参笔记](https://industrialmonitordirect.com/sv/blogs/knowledgebase/tuning-mpc-controllers-in-acados-drone-flight-control-methods?srsltid=AfmBOoqRzj9DNj-jP_uheKDShNH6fUbLBcGh-YdEyEuxSWXcMQTF_qps)，工程博客级证据）；
- **权重**：Bryson 法则 $Q_{ii} = 1/x_{max}^2$ 按通道最大允许误差归一；`w_du`（本工程 0.05）对应 move suppression，直接决定操舵频率与舵机磨损；速率硬约束 + 输出软约束（slack）是工业标配；
- **采样周期 vs 求解耗时**：最坏求解时间 ≪ 采样周期，余量留给状态估计与通信；HIL 验证报告最坏值与分布；
- **执行器模型**：舵角速率饱和、推力饱和必须进约束（本工程已用速率约束等效处理）；
- **两级结构**：船舶欠驱动主流是制导层（LOS 运动学）+ 控制层（动力学跟踪）级联；本工程 Tier-1+Tier-2 本质是"速度级+位姿级"两级揉进同一 QP，与 LOS+控制器级联同构。ILOS（积分 LOS 抗恒定海流，Borhaug CDC 2008）、ALOS（自适应侧滑角，Fossen TCST 2023）、VFALOS（[arXiv:2403.17448](https://arxiv.org/abs/2403.17448v2)）为制导层变体。

## 7.4 路线选择建议（执行顺序）

1. **先 P0 全部闭环**（尤其 P0-1 控制分配与 P0-2 求解兜底）——否则实船闭环无从谈起；
2. **P1 按"求解器工程（P1-1~3）→ 训练配置固化（P1-4）→ 数据与辨识质量（P1-5~8）→ MMG 部署链路（P1-9）"推进**——多数改动在单文件级，风险低、可独立验收；
3. **P2 以 P2-1（offset-free）与 P2-2（终端代价）为最高性价比入口**——两者都只改 QP 的 P/q，不动系统结构，却分别补上"稳态抗扰"与"稳定性保证"两块理论短板；
4. **建模范式的取舍**（Koopman 线性 latent 的 slope≈0.70 结构下界 vs MMG+残差的实测优势）建议用 P1-9 的同口径闭环对比做最终裁决，再决定是否投入 P2-5~P2-9 的 Koopman 侧深度改造；
5. 全过程保持本工程既有纪律：**评估先行**（任何改动过 evalkit 同口径指标 + verdict）、**归一化纪律**（stats 全链路同源）、**跨语言验证**（改 QP/encoder 后重跑第 5 章验证链）。
