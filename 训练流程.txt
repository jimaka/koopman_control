       Koopman 模型终极数据流转图：【物理航次切分】 + 【无重叠滑动窗口】 + 【全局打乱】
========================================================================================

                          [ 第一阶段：离线物理特征提取 ]
                  (执行 convert_bag_to_npz_1.py，无任何修改)
                          -----------------------
     原始 ROS Bag 文件 (.bag)
             │
             ▼
    process_bag() ─────────────> 提取 10Hz 的 Pos, Vel, pqr, Yaw 与控制量
             │
             ▼
    split_by_logic() ──────────> 依据 CPP_PHASES 截取特定的时间窗：
             │                   - 段0: STR_STEP_FORWARD (0~1499s)[cite: 8]
             │                   - 段1: STR_STEP_BACK (1501~2999s)[cite: 8]
             │                   - 段4: ZIGZAG_ALL (7001~12999s)[cite: 8]
             │                   - 段6: PRBS_EXCITATION (14001~14999s)[cite: 8]
             ▼
    保存至单一文件: koopman_dataset_v1.npz (包含 7 个独立、连贯的物理航行段字典)[cite: 8]

========================================================================================
                                 ↑ 离线存储界限 ↑
----------------------------------------------------------------------------------------
                                 ↓ 在线训练界限 ↓
========================================================================================

                          [ 第二阶段：滑动窗口提取与全局打乱 ]
                     (在 PyTorch Dataset / DataLoader 初始化时执行)
                          ------------------------------------
    加载 koopman_dataset_v1.npz
             │
             ▼
    【步骤 A：无重叠滑动提取 (Sliding Window Extraction)】
    遍历 7 个物理段，设置 预测步长(Pred_len=10), 窗口滑动步长(Stride=10)
             │
             ├─ 从段0(直线) 提取: Block_0 (t=0~10), Block_1 (t=10~20) ...
             ├─ 从段4(Z型)  提取: Block_M (t=0~10), Block_{M+1} (t=10~20) ...
             └─ 从段6(PRBS) 提取: Block_N (t=0~10), Block_{N+1} (t=10~20) ...
             │
             ▼
    【步骤 B：构建全局数据池 (Global Pool)】
    汇集所有物理段提取出的总计上万个独立的 10 步数据包 (Data Blocks)
             │
             ▼
    【步骤 C：全局随机打乱 (Global Shuffle)】
    random.shuffle(Global_Pool)  --> 彻底打乱数据包的先后顺序，抹平油门/速度分布差异！
    (注：打乱的是 Block 之间的顺序，Block 内部的 10 步时序因果关系完好无损)

========================================================================================

                          [ 第三阶段：安全切分与隔离标准化 ]
                          ----------------------------------
    从打乱后的 Global_Pool 中按比例切分索引：
             │
             ├─> 70% 划入 Train Dataset
             ├─> 15% 划入 Val Dataset
             └─> 15% 划入 Test Dataset
             │
             ▼
    【防泄漏标准化 (No-Leakage Normalization)】
    1. 严格只遍历 Train Dataset 包含的数据包，计算全局的均值(Mean)和标准差(Std)。
    2. 将算出的 Mean/Std 应用到 Train、Val、Test 的输入和输出张量上。

========================================================================================

                          [ 第四阶段：模型前向推演与反向传播 ]
                          ----------------------------------
    从 Train DataLoader 获取一个完全随机分布的 Batch (包含大油门、Z型转弯、PRBS等混合工况)
             │
    [ 局部坐标系转换 ]: 将每个样本的未来轨迹转换到各自 t=0 时刻的相对坐标系
             │
    [ Koopman 多步推演 ]: 
      z_t = Encoder(x_t)
      z_{t+n} = A * z_{t+n-1} + B * u_{t+n-1}  (执行 N 步)
      x_hat_{t+n} = Decoder(z_{t+n})
             │
    [ 综合 Loss 计算 ]: L_pred(推演) + L_recon(重建) + L_linear(线性) + L_stab(谱半径)
             │
    [ 优化器更新模型 ] ──> [ StepLR 按步数强制衰减学习率 ] ──> [ TensorBoard 记录监控 ]
